# 用户详情直接设置代理群

2026-10-09，修正首次版本必须先进行群级绑定才能选择的问题。

用户详情的“代理群 → 设置/更换”直接打开原有 OpenIM 群聊列表，无需先去代理群绑定页面。选择后调用一次 `user.agent_group`，携带 `bindIfNeeded:true`。服务端将新群绑定、用户归属和审计作为同一事务提交；清除操作保留原有群级绑定，不影响其他用户。

新群要求操作者具备当前下注群运营权限及所选群的 OpenIM 管理身份，支持本租户 owner/admin。已绑定其他下注群、选择下注群、用户无返水或权限不足均拒绝，不会留下部分绑定。独立群级绑定页面仍维持原有 owner 权限。

继续复用现有用户详情、群聊列表和 AppDialog，没有增加重复选择器。数据来源为 OpenIM 群资料及 Go 归属接口，支持浅色/深色主题。已核对 99chat d7c3c65 的用户详情文件，未发现对应代理群直接绑定功能，本次按明确需求扩展当前组件。

验证：代理模块 15 项客户端测试通过，覆盖无预绑定时选择、一次保存、清除、权限与作用域保护及浅/深色；修改范围静态检查通过。Go 单元测试和静态检查通过，隔离 MySQL 验证管理员首次设置、幂等审计、能力刷新、权限拒绝、跨租户冲突和保存后的强制回滚；既有代理资格、归属及资金生命周期测试通过。Chat 相关测试与 RPC 构建通过。

服务端更新不创建或修改任何真实用户的代理群归属；生产验证只读。真实设备联调及 Android/iOS 安装包未验证，当前环境仍缺少 Java。
