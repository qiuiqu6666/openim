# 钱包未接入页面补接

本次依据用户提供的《钱包页面接口文档》补接原先使用占位实现的钱包功能。
用户明确要求“只对接当前没有对接接口的页面，已经对接的页面不要动”。
已接入的红包、转账、领取和支付密码页面保留原业务；新增钱包流程调用现有
支付密码服务和页面，不另建一套密码接口。

## 页面与数据

| 页面/动作 | 接入接口 | 显示边界 |
| --- | --- | --- |
| 首页币种数量 | `GET /chat/fund/balances` | USDT、TRX、BI99 的可用数量，冻结数量不计入可消费余额 |
| 充值地址/二维码 | `GET /chat/fund/deposit-address` | TRON 主网，共用 USDT/TRX 地址，生成中每 4 秒重查，离开页面停止 |
| 充值记录 | `GET /chat/fund/deposits` | 最近 100 条，保留同一交易哈希中的多个充值事件 |
| 链上提现 | `POST /chat/fund/withdrawals` | 只支持 USDT/TRX，实际手续费以返回为准 |
| 币种兑换（首页“划转”） | `POST /chat/fund/swaps` | USDT/TRX/BI99 六个兑换方向，实际所得以返回为准 |
| 新钱包交易的订单核对 | `GET /chat/fund/orders/:orderID` | 只用已知服务端单号查询原交易，不重新提交未确认交易 |

钱包“转出给好友”的占位入口转接现有已接入的转账页面。接收人来自 SDK
联系人中的真实用户 ID，不能将展示短号直接当作 `recvID`。原转账页面和接口
实现不作修改；提现入口仅列出 USDT/TRX，好友入口继续保留平台币。

金额保持十进制字符串与整数最小单位。BI99 请求枚举不使用展示名称代替。
首页数量和历史记录金额保留两位小数；提交金额和可用余额比较保留币种原精度，
不经过浮点数。
充值回滚后的负可用余额保留原值，不截成零。

完整钱包流水、提现订单列表、充值分页、提现费率/限额查询、闪兑报价预览、
提现链上确认状态、资产估值和历史走势均无对应用户接口。页面显示明确的
暂无数据/暂不支持提示，不使用示例价格、示例手续费、虚构月份或本地估算。
充值记录没有时间；记录详情保留区块高度、地址、哈希和实际充值状态。
`orphaned` 表示充值因回滚撤销，不能显示成功入账。`withdraw_done`
只表示广播成功，显示“已提交链上”，不能声称收款方已到账。

## 请求与恢复

### 充值和提现规则

`GET /chat/fund/deposit-address` 现返回 `data.currencyRules.USDT/TRX`：最低充值 `minDepositAmount`、最低提现 `minWithdrawAmount`、固定手续费 `withdrawFee`、手续费币种 `withdrawFeeCurrency`、入账账户 `receivingAccountType`、预计到账秒数 `estimatedArrivalSeconds`、累计提现解锁确认数 `withdrawUnlockConfirmations` 与 `memoRequired`。

前端按当前语言显示这些实际值，金额始终保留十进制字符串和整数精度。后续读取采用最新响应；新提现授权前重查当前规则及余额，最低提现不含手续费，可用余额需覆盖本金加同币种手续费。未确认订单继续按原业务单号查询，不因新规则失去恢复入口。缺失规则不视为免费或无限额。充值 QR、复制和分享继续使用 `data.address`。

新钱包请求复用现有 Chat 登录令牌、配置地址及传输层。每个请求使用独立
`operationID`，业务单号 `clientOrderID` 按账号和服务器持久化。
冻结原交易参数、写入提交标记后才发送资金请求，不保存支付密码。

提现和兑换提交超时、成功响应不完整或解析冲突时，原交易保留为未确认。
如果已返回真实服务端单号，保留该单号并通过 GET 核对；没有单号时保留业务
单号以供人工核对。页面重开、重复点击或重新输入密码不会重新 POST 未确认
交易。明确的业务拒绝可以沿用原业务单号重试；创建新交易需用户单独操作。

充值通知以 99Pay 的稳定 `depositNoticeID` 去重，并按账号/服务器触发钱包
余额与记录的重新查询。通知内容不用于直接增加或扣减金额。页面异步返回、
地址轮询和余额刷新均检查账户归属和页面生命周期。

## 验证边界

使用模拟传输验证请求路径、Chat 鉴权、业务单号、精确金额和恢复逻辑，不向
线上发送资金写请求。实际账户余额、真实充值和真实提现仍需登录后的环境
验证；未登录的路由检查不能作为资金交易成功的证据。
