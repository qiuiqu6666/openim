# 收藏详情界面优化

2026-10-05，针对用户提供的语音收藏详情截图，继续使用现有收藏数据、原件授权、校验下载及发送链路。

## 界面

- 标题居中，返回使用蓝色箭头；删除仍保留确认和版本冲突处理。
- 语音卡片合并重复附件行：标题与文件大小同一行，56px 圆形播放/暂停按钮配合蓝色进度条，已播/总时长分列。总时长优先使用播放器读取结果，尚未读取时才使用收藏元数据。
- 原件加载、播放器加载和失败重试复用同一播放器布局；拖动时即时预览时间，松手提交定位，保留播放结束后重播、后台暂停与销毁释放。
- 来源和收藏时间独立排版，时间转为手机本地时区，仅显示服务端提供的字段。
- 底部主按钮使用项目强调色、字体和圆角，操作区支持安全区；小屏或大字号时多个操作纵排。纯只读详情不占用空操作区。
- 未增加装饰波形、封面或新播放插件。复用 `GlassAppBar`、Material 按钮/Slider、LoadingView、just_audio 和 AppTokens；新增仅为收藏详情的展示布局与尺寸定义。

核对了 `reference-99chat/lib/src/pages/favorites/favorite_message_detail_page.dart` 的居中标题、蓝色返回和简洁详情结构。该参考页未提供语音详情播放器，本次播放器为现有 OpenIM 组件的视觉优化，不声称像素复刻。
