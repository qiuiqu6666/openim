# 用户代理群入口验证

2026-10-09，基于 `cf8f7bd` 扩展用户代理群归属功能。

## 行为与边界

管理员在下注群的用户详情中设置、更换或清除代理群。群级绑定继续由有权限的 owner 建立；选择器复用已有群聊列表，只允许选择绑定当前下注群的群。设置或更换要求目标用户返水比例大于 0；清除不受此限制。

有效三公账户、正返水比例、明确的用户归属和真实群成员资格共同决定个人代理权限，不需要全局运营特权。用户进入指定群聊可打开三公代理，查看本人和授权下级的统计、流水、返水。运营管理接口保持原有特权、OpenIM 管理员与租户授权校验。更换、清除、停用或退群后，原群请求及旧幂等请求均重新校验；客户端收到权限变化后隐藏入口并关闭失效页面。

## 复用与实现归属

已核对 99chat `d7c3c655b20dd06458d1882b114e68c1c24133e3` 的 `lib/src/pages/group_game/sangong_agent_dashboard_page.dart` 和 `sangong_agent_team_page.dart`。沿用当前移植的总览、团队、个人页面；用户归属设置是本次扩展，未声称参考仓库已有相同机制。

复用 OpenIM 群聊列表、真实群名/头像、AppDialog、现有主题和路由。新增 `agents/user_group/` 组件独立拥有查询/保存状态，避免把新职责加入已有用户报表大文件；新增 access policy 集中定义个人代理权限。数据来自 Go 用户归属接口与当前账号的私有群能力，公开群摘要不作为授权依据。

## 验证结果

- 核心客户端回归 101 项通过：代理页面、入口与路由、普通用户授权、管理拒绝、失效关闭、设置/清除、群列表选择、迟到响应和浅色/深色主题。
- 补充入口完整数据展示与管理权限诊断 33 项通过（与核心测试存在重叠，不累加为独立用例数量）。
- 修改范围静态检查通过。
- Go 三公单元测试、静态检查通过；真实隔离 MySQL 覆盖成员资格、能力查询、未分配拒绝、零比例拒绝、换群、清除、旧幂等重试、越权读取及既有资金流程。
- Chat 三公相关测试和 bridge 测试通过，Chat RPC 构建成功。服务端已备份并更新，用户归属只读接口返回 HTTP 200，未修改生产绑定或余额。
- 扩大回归发现 4 项既有失败，均在原始 `cf8f7bd` 独立副本复现：无公共摘要时结算图参数预期、状态条快照请求次数、规则页抽水字段展示的浅/深色用例。本次未调整这些业务行为。
- Chat 全量静态检查存在既有问题：MongoDB 两处无键结构体初始化，以及消息撤回测试复制互斥锁；三公模块静态检查通过。
