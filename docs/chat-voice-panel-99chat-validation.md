# 99chat 语音录制面板迁移验证

这是 2026-10-05 初版复刻的历史验证记录。随后按用户新要求重设计了语音区域；当前界面及验证方式见 [语音区域重设计验证](chat-voice-panel-redesign-validation.md)。这里记录的旧语音像素对比不再作为当前设计的验收标准。

参考版本：`reference-99chat` 的 `d7c3c65`。本次使用正式聊天页 TUIKit 移动端 `narrow.dart` 和 `tim_uikit_send_sound_message.dart`，按源码迁移布局与手势，保留 OpenIM 录音与发送底层。

## 交付行为

- 语音模式显示原版空灰输入框和 248px 加手机底部安全区的面板，麦克风为 88px，原渐变、阴影、42px 图标、间距和说明文字均使用源码值。
- 录音显示全屏 42% 遮罩、底部深色面板、中央九点、左右取消/转文字按钮以及随实际音量变化的波形。
- 最后松手位置决定分支；取消手势、第二根手指、快速松手、切换输入和退出页面都不会误发。60 秒自动结束保留当前取消或转文字意图。
- 不丢失草稿、光标或聊天自定义背景。转文字沿用当前识别服务、编辑确认、失败重试及发送原语音流程。
- `VoiceRecorderWidget` 增加可选 controller/builder，默认长按录音界面继续保留。一个控制器只能绑定一个原生录音器；同一元素位置避免切换布局时重复绑定。
- 启动、停止和文件交付分别受状态保护。准备失败或超时返回空闲；迟到的原生启动只停止和删除文件，后台清理完成前不能再次启动。退出后不回调死页面，已交付文件由原业务回调处理。

## 验证范围

`test/widgets/chat/chat_voice_panel_test.dart` 通过独立抄录源码的 reference fixture 比较原始 RGBA 像素：16 组 idle/按下面板，加 24 组录音发送、取消和转换浮层，共 40 组。覆盖日夜主题、320/375 宽度、0/34 底部安全区和真实锚点/回退锚点。原输入栏 32 组独立像素对比继续通过。

`chat_voice_gesture_test.dart` 8 项使用正式录音组件和真实 Pointer 事件，验证即时出现浮层、取消、最终松手、第二指取消、时长上限、准备中切换和卸载。它们同时确认没有调用音频解码或业务发送，避免失败回调掩盖误发。

本地插件 `voice_recorder_controller_test.dart` 7 项通过录音、权限和路径 MethodChannel mock 及实际临时文件，验证重复启动/停止、原生振幅、快速松手/取消、权限拒绝、异常后重试、卸载删除和交付文件所有权。SDK 语音发送、播放、转文字、草稿、输入与进入聊天页面的相关回归也已执行。

正式 `ChatPage` 预览使用同一页面、输入组件和录音组件；只替换 SDK、原生录音及预览字体。日夜两场景通过，并生成 `docs/previews/chat-composer-99chat-{light,dark}-voice*.png`，包含面板、录音、取消和转文字状态。预览禁用 debug banner，保留真实阴影。

验证仅确认同一 Flutter 环境内的源码样式一致、组件行为和模拟原生链路。Android/iOS 真机麦克风权限、真实音频质量、键盘动画及系统字体仍需设备验收。

2026-10-05 最终记录：30 项面板/手势/插件/正式页验证通过，139 项相关回归通过，合计 169 项（重复运行不重复计数）。改动文件静态分析无问题，Android debug 构建成功；独立交付包为 `build/app/outputs/flutter-apk/app-chat-voice-panel-99chat-debug.apk`。

## 文件职责

`chat_voice_tokens.dart` 管理几何和颜色，`voice/` 管理纯渲染和命中位置，`HoldToRecordButton` 管理录音手势与文件交付，ChatPage 仅启用 expanded 模式。本地录音插件保留原可定制样式 API，因兼容入口与新增生命周期保护合计超过 500 行；新控制器独立维护，不复制另一套原生录音器。
