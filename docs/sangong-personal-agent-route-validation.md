# 用户详情输入群 ID 设置代理群

2026-10-09。此实现替代此前“从群聊列表选择并自动绑定下注群”的流程。

用户详情点击设置/更换，直接输入群 ID 保存个人归属；清除仍需确认。显示已保存的群名和群 ID，群名查询失败时仍可更改。设置无需预先群级绑定，也不要求操作者加入目标群或是目标群管理员；保留当前下注厅管理权限、目标用户成员/账户及正返水比例校验。普通用户进入绑定群后仅可查看本人及授权下级，仍须为真实群成员。

保存关系是当前厅＋用户＋群。一个群可供同厅多个用户或不同厅的不同用户使用；同一用户＋群只能对应一个厅，唯一索引防止并发覆盖。查询、代理命令、入口能力均按个人归属定位厅，旧群级绑定不再决定个人数据归属。更换、清除、比例归零、停用或退出群时重新校验访问和重试；原群和新群均刷新入口，其他用户不受清除影响。若该群同时是其他厅的下注群，此用户的个人入口优先使用明确设置的代理归属，不授予其他厅管理权限。

对照旧 99chat `d7c3c655b20dd06458d1882b114e68c1c24133e3` 的 `lib/src/api/agent_rebate_api.dart` 中 `bindAgentChatGroup`，以及原 Java `AgentController.saveChatBinding`、`AgentChatBindingRepository`、`AgentEntryController` 的保存与入口判断。未定位到旧输入框页面，界面按用户要求复用当前 `AppDialog.prompt`、主题和权限保护组件，没有新增重复组件。正式数据来自 Go 归属接口和 OpenIM 群资料。

OpenIM 群 ID 只去首尾空格，保留大小写、`group_` 及实际 `@`。群资料复制操作提供真实 ID；手动填写带 `@` 的显示形式时优先精确匹配，仅在 IM 确认去掉前缀后的群存在时采用其真实 ID。不能直接复用旧腾讯版删除全部 `@` 的规则。
