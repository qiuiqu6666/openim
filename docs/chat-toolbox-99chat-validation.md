# 聊天更多面板迁移验证

2026-10-05，对照本地 99chat `d7c3c65` 的生产 `TIMUIKitMorePanel`、移动端 `narrow.dart`、聊天入口配置与 `DefTheme`。使用正式面板及原图，不复制参考仓库的腾讯 SDK、状态或测试数据。

## 实现

- 单聊首屏为相册、拍摄、收藏、音视频通话、个人名片、文件、红包、转账；四列八项，可左右分页。群聊隐藏通话，具备现有权限时群直播位于首屏第八项。
- 原有录音、音频、位置和群扩展功能保留；公开组件仍支持原来的格式化文字和自定义表情回调，应用未配置的项不新增业务能力。
- 使用参考 SVG/PNG、圆角底色、间距和主题；原图保留画布留白，程序补充图标统一视觉大小。资源逐个 SHA256 对照一致。
- 内容高度 248px 加一份底部安全区，200ms easeOutCubic 展开。切换表情、录音和键盘时互斥；闭合普通输入保留安全区，内部面板展开过程中使用终态约束，避免挤压内容。
- 继续复用 `ChatInputBox`、现有工具回调、`Permissions`、OpenIM SDK 和各业务模块；没有修改好友、发送、资金或群权限接口。输入与焦点控制器、草稿仍由调用方持有。
- 大字、小屏和受限高度支持页内纵向滚动；权限变化导致当前页不存在时回到第一页。

相关 51 项测试通过，包括更多面板的回调与权限、群差异、动态分页、小屏大字、日夜主题、禁用入口、输入模式互斥、草稿与选区、焦点及强制关闭、安全区与中间动画尺寸，以及原输入栏独立参考渲染、表情、资金和名片入口。

修改范围静态检查无问题。正式组件的亮暗两页预览保存于 `docs/previews/chat-toolbox-{light,dark}-page-{1,2}.png`。预览中的完整工具能力由测试回调注入，应用只显示其现有配置与权限可用的入口。
