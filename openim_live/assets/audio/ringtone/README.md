# 呼出回铃音

`outgoing_ringback.wav` 为本模块原创生成的提示音，没有复制 99chat、TUICallKit 或远端音频。
与 99chat 分开使用来电铃声、呼出回铃声的行为一致，声音内容为 425 Hz 纯音，1 秒响、4 秒停。
首音直接从文件开头播放，10 ms 淡入淡出防止 PCM 接缝爆音；16 kHz、单声道、16 位 PCM，完整循环 5 秒。

使用 `python generate_ringback.py` 可离线、确定性重新生成。脚本只在开发期生成静态资源，
客户端不执行合成或下载。来电继续使用 `openim_common/assets/audio/live_ring.wav`。

由 `signaling/call_ringtone.dart` 单播放器负责循环、去重及停止；控制器在呼出邀请和 RTC 证书成功后启动，
不等待音频装载阻塞 RTC 加入。收到接听/拒绝/取消等信号立即使回铃失效，旧资产装载完成不得重新播放。
Android 回铃只配置播放器自己的通信提示音属性；iOS 只激活当前音频会话，不设置音乐类别、
全局音量、扬声器或蓝牙路由，不在停止时停用 RTC 的音频会话。
来电保留原 WAV 并使用通知铃声音量流；此播放器不独立抢占/释放 Android 音频焦点，
避免与 RTC 接听时的焦点交接冲突。iOS 在 RTC 启动前保留当前音频类别（可能为默认 SoloAmbient），
硬件静音时是否可听与接听后焦点、听筒/外放行为必须在手机验证。

自动测试验证 PCM 音调/静音节奏、回铃/来电资产选择、并发停止及控制器生命周期。
实机通话、iPhone 静音开关、听筒/外放/蓝牙音量仍需要设备验证。
