# 图片气泡清晰度

`../chat_picture_view.dart` 保留公共气泡入口、圆角和文件检查生命周期。聊天图片气泡默认最大宽度为 90.w（比上一档 100.w 再缩小 10%），高度按图片比例同步缩小，不放大较小原图。调用者显式传入的 maxDisplayWidth/maxDisplayHeight 继续优先，长按会话预览保留独立尺寸。
`chat_picture_quality.dart` 管理来源选择和解码尺寸，参考 99chat 图片消息组件中裁切长图与普通缩略图分开计算解码的做法。

气泡按 `BoxFit.fitWidth` 显示时，解码需要保留「显示宽度 × DPR」的横向像素，再按原图比例计算完整解码高度。裁切长图不能把气泡高度直接作为解码高度，否则会先缩成窄条，再放大成模糊的局部预览。

裁切长图使用宽高比 3:5 的竖向长方形气泡，按默认宽度或调用者指定宽度计算可见高度，统一顶部对齐，优先显示标题和开头内容；本地原图、网络原图及加载/失败时的缩略图使用相同尺寸与对齐方式。普通图片维持居中，已有尺寸约束和圆角不变。图片来源与高清解码策略、点击全屏查看均不因气泡缩小而改变。

每张气泡解码限制为 4 MiPixels（RGBA 约 16 MiB），最长边 8192 像素，不放大小于目标的源图。普通图片继续使用缩略图；裁切长图优先使用尺寸足够的大图，否则使用原图，加载中及失败时回退缩略图。签名 URL 不重写缩放参数，业务 URL 解析继续交给已有 `ImageUtil`。

测试位于 `test/widgets/chat/picture/chat_picture_quality_test.dart`，覆盖真实文件解码、高密度屏、极端比例内存边界、图片档位及普通图片；文件异步生命周期仍由 `test/chat_picture_view_lifecycle_test.dart` 覆盖。
