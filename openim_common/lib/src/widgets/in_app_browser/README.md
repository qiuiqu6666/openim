# 应用内网页

当前生产入口 `openInAppBrowser` 使用 `url_launcher` 的 `inAppBrowserView`：iOS 为 SFSafariViewController，Android 为 Custom Tabs，导航栏、分享及关闭由系统浏览器提供。只接收无用户凭据的 HTTP/HTTPS 链接；不支持此模式或启动失败时返回 false，由调用方提示，不回退到外部浏览器或自绘 WebView。Android Manifest 配置了 CustomTabsService 查询。系统面板不提供应用自管的多网页卡片、收起栏和聊天内分享能力。

以下为保留的旧组件说明；生产入口已不再创建这些界面。旧组件测试直接构造旧路由，系统入口另由 `system_browser_test.dart` 验证。

应用在 `AppView` 安装 `InAppBrowserHost`，让网页位于业务导航之外。收起后切换、返回或替换业务页面都不会重新创建 WebView，展开继续使用原控制器、历史和滚动位置。未安装 Host 的独立组件环境继续使用原路由入口。

系统返回处理在 `main` 中先于 MaterialApp 安装：展开时优先回退网页历史或关闭，收起时交给业务导航。应用内分享期间暂时隐藏浏览器层，结束后恢复原实例；退出账号时清除全部网页。打开新外链会把已有网页保留在后层，每页独立保留控制器、历史和滚动位置。底部只展示一条完整收起栏；多页时露出固定高度的后层卡片边缘，并显示网页数量按钮。点击数量可查看全部页面并直接切换，选中的原实例移至最上层；列表支持滚动、点遮罩或系统返回关闭。展开时不露出后层底栏，关闭最上层网页后自然露出前一个。

公开入口为 `openInAppBrowser(uri, context: context)`，无上下文的聊天/扫码动作可使用现有 GetX 根导航。返回值表示页面是否已入栈，不等待用户关闭网页。

复用现有 webview_flutter、AppTokens 和 Material 导航控件；对照 99chat 的 privacy_webview.dart 内嵌网页结构，扩展为跨模块通用外链页。网页内容直接来自目标网站，不注入 IM token、用户资料或原生 JS 桥接。

- Android/iOS 使用内嵌 WebView；其他平台显示不支持提示，不自动跳转外部浏览器。
- 仅允许无用户凭据的 HTTP/HTTPS 地址，重定向也经过检查，不唤起外部应用。
- 使用保留顶部安全区的圆角弹层，顶部显示当前网址和“完成”；完成直接关闭，系统返回优先回退网页历史，无历史时退出。底部前进/后退按钮根据历史启用，刷新保留历史，加载失败重试创建新视图。
- 底部分享通过 InAppBrowserShare 接入应用的联系人选择、ChatMessageSender 与账号会话保护，发送网页标题和链接，不唤起系统分享面板；仅用户主动点击“在浏览器中打开”时交给外部浏览器，网站重定向不会自动唤起其他应用。
- `InAppBrowserRoute` 联动网页上滑与底页缩小圆角，关闭时反向恢复；通过 Flutter delegated transition 同时兼容 GetX 和 Material 路由，不复制或重建底页。减少动画时直接完成自动过渡。按住顶部网址栏或底部工具栏下拉时，新页跟手移动、底页同步恢复；超过屏幕高度的 25% 或快速下滑收起为底部网址条，否则回弹。收起后保留 WebView、历史和页面状态，移除遮罩以操作底页，并为底条预留空间；点击网址或向上箭头重新展开，也可按住底条跟手上滑：达到展开距离或快速上滑即展开，不足则回到底条，点击关闭按钮释放页面。网页内容保留原生滚动手势，避免滑动网页时误关。
- 主文档加载错误及 30 秒超时显示恢复页面；子资源错误不阻断网页，旧视图和销毁后的回调不写入状态。
- 原生页面外壳支持亮暗主题、安全区域和文字缩放；网站内容遵循网站自身主题。
- 电话、邮件、分享唤起、附件下载和安装更新不属于普通网页浏览，保留其专用处理。

主文档到顶部后，继续向下拖动会带动整个窗口；未到顶部时保持网页滚动。双指操作取消窗口拖动，短距离拖动回弹。底栏可点击或上滑展开最上层网页。此行为由原生滚动位置通知与 `in_app_browser_edge_drag.dart` 指针观察组件接入现有路由手势，不增加依赖或网站 JS 桥接。网页内部独立滚动容器和跨域 iframe 的边界无法由主文档原生滚动位置精确表示，仍需目标网站真机验证。

测试：应用根目录 `test/widgets/in_app_browser/`，使用项目现有 WebView 平台假实现方式覆盖导航、多页保留、顶端下拉、协议限制、重试、生命周期、亮暗主题及小屏大字。

窗口下拉由浏览器自身管理，不登记为 Navigator 的返回手势，避免重复开始或中断后导致 ModalRoute 一直忽略点击。网页边缘下拉与外层工具栏拖动分别接收结束、取消事件；切换网页会清理旧拖动状态，并让旧动画的异步完成回调失效。`integration_test/browser/browser_touch_device_test.dart` 使用本机 HTTP 测试页和真实 WebView，验证多轮打开、收起、恢复、关闭后网页按钮的点击计数，生产环境不注入该测试页。
