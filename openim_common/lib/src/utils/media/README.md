# 共享媒体来源兼容

`video_gallery/` 是聊天图片/视频全屏预览的视频保存入口，区分视频与图片，负责流式下载、容器扩展名、相册权限、真实保存结果及等待超时。详见其维护说明。

`openim_media_url.dart` 负责 OpenIM 对象地址兼容，不改变签名地址的域名、路径或查询参数。

`native_media_file.dart` 供聊天语音和移动端视频共用。iOS 原生播放器依赖本地文件后缀，通用缓存根据 HTTP Content-Type 保存的 `.bin` 文件可能无法解码。准备播放时只读取前 64 字节，复用 `mime` 并识别 M4A/MP4/MOV 容器头；已知内容与后缀不一致时，流式写入共享 `DefaultCacheManager` 管理的副本，保留原始文件。缓存键包含源路径、大小与修改时间；并发准备复用同一个写入，重复播放复用副本。未知格式不猜测，也不转码；Android 保持原路径。

`widgets/native_media_video.dart` 保持原有本地文件、缓存、网络顺序。iOS 网络初始化失败后额外尝试完整下载并规范后缀，绕开媒体响应头/Range 兼容问题；下载和原生装载均有超时，关闭页面后迟到结果只可留在缓存。下载沿用 `video_media_cache.dart`，保留调用方传入的请求头，带请求头的缓存按 URL 与请求头摘要隔离。不会另加账号令牌。

视频仅在存在远程来源时准备共享缓存副本；收藏等纯本地预览继续把原文件交给播放器，保留所属模块关闭页面时销毁临时原件的语义。

界面继续使用现有语音和视频组件，亮暗主题与消息 SDK 数据保持不变。回归覆盖文件格式识别、缓存复用、原文件保留、语音本地失败回退、视频网络失败回退以及退出后的迟到结果。Windows 测试使用原生播放器替身，仍需 iPhone 真机验证实际文件解码、拖动播放和连续播放。
