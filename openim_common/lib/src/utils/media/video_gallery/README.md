# 视频保存到相册

`VideoGallerySaver` 负责权限、视频下载、本地文件准备与原生相册写入；`VideoGalleryAction` 负责预览所属的等待提示、下载进度、防重复点击和结果反馈。聊天预览通过 `MediaSource.isVideo` 分流，图片继续使用原有图片保存流程，旧 `HttpUtil.saveUrlVideo` 委托到相同视频实现。

- iOS 使用添加照片权限，Android 29+ 使用 MediaStore，旧 Android 请求存储权限。沿用现有相册插件及 iOS 权限声明，不新增原生插件。
- 优先可用的本地原件，其次内存视频，再下载远程原件；本地路径不存在时可回退 URL。下载使用独立 Dio，不向对象存储附加登录令牌，保留已解析来源中的签名查询参数。
- 下载直接写入本次独占临时目录，等待下载 Future 完成；未知 Content-Length 不依赖进度判断结束。连接 20 秒、读取空闲 30 秒、操作总时限 5 分钟，超时取消网络请求。进度最多每 250 毫秒更新一次。
- 只读取容器头来选择 MP4/MOV 等扩展名，拒绝空响应、HTML 和音频；不会将视频整体读入内存后调用图片保存。原文件不修改，临时副本在原生写入完成后清理。不做视频编码转码，系统不支持的编码仍可能被相册拒绝。
- 必须等原生返回 `isSuccess == true` 才提示成功；失败、权限拒绝、下载失败和超时分别反馈。原生等待最多 90 秒。原生操作不能取消，超时后保留其临时文件并阻止重复视频写入，实际回调到达后清理；提示用户先检查相册。
- 预览关闭会取消下载；账号或 IM 凭证改变后不再提交相册写入、不显示迟到结果。已提交给原生相册的写入无法撤回。下载完成与相册写入是两个不同阶段，等待提示在异常和完成路径均结束。
- 调试日志只记录结果类型与耗时，不记录签名 URL、令牌、账号或本地路径。

回归：`test/utils/media/video_gallery_saver_test.dart` 覆盖文件保存接口、格式及扩展名、签名链接、缺少 Content-Length、空文件/HTML、权限拒绝、下载取消/超时、原生失败/迟到完成和重复点击；`test/widgets/media_browser/media_browser_video_save_test.dart` 验证真实共享预览回调按视频分流、去重、关闭转圈并保留成功提示。原生相册方法在 Windows 测试中使用替身，实际 Android/iOS 相册写入仍需真机验收。
