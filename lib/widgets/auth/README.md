# 认证界面

登录、注册和找回密码按本地 `reference-99chat` 的 `login.dart`、`forgot_password.dart` 及 `auth_widgets.dart` 实现：蓝色欢迎区、顶部页签、圆角白色表单区、灰底输入框及版本页脚。认证页面与参考一样固定使用浅色，业务页面沿用原有主题。

- `auth_reference_layout.dart`：手机与宽屏认证布局、页签、返回键和键盘滚动。
- `auth_form_scaffold.dart`：99chat 设备验证等二次认证使用的白底标题、副标题、分割线和可滚动表单，返回键视觉 36、点击区域 48；认证配色同参考固定浅色。
- `auth_info_banner.dart`：二次认证通用的蓝底盾牌提示条。
- `auth_reference_fields.dart`：参考的普通／组合输入框，保留自动填充、焦点与清除按钮。
- `auth_reference_field_frame.dart`：两个输入框共用的聚焦／错误边框、字号放大后的高度适配。
- `auth_reference_feedback.dart`：字段下方提示与可换行的表单业务错误，支持屏幕阅读器播报。
- `auth_reference_controls.dart`：按钮、国家区号、真实发送成功后的验证码倒计时和版本页脚。
- `auth_reference_tokens.dart`：参考认证页面的固定颜色与尺寸。
- `auth_form_rules.dart`：已有账号／验证码校验和当前语言提示；注册独立规则位于 `pages/register/rules`。

注册采用两步表单。第一步填写账号、验证码、密码及确认密码，点击“下一步”校验验证码；第二步填写昵称、选填头像并显示选图预览，点击“完成注册”执行注册、OpenIM 登录及头像上传。上传失败停留在第二步，可重新选择并重试头像上传，账号创建后锁定昵称和返回第一步的入口，重试不重复注册。找回密码在单页提交验证码与两次密码，验证成功后执行重置，成功返回登录页。旧验证码及独立设置／重置密码路由保留兼容，第二步仍兼容旧入口未提供密码时的密码补填。

后端错误继续由共享请求层读取响应 `errCode` 并按当前语言显示。阿里云人机验证与 `/account/code/send` 的真实结果检查保持生效。与参考服务端的契约差异详见 `docs/auth-99chat-api-contract.md`。

注册的业务错误（如昵称已占用）使用现有 `IMViews.showToast` 公共居中提示，注册和验证码校验请求关闭底层自动提示，由有效页面处理一次；不在注册按钮上方放置错误框。可编辑字段的本地校验仍显示在字段下方。

在参考蓝白结构上，按用户授权收紧头部与表单间距：欢迎语 26、页签 20、输入文字 16、标签 14；输入框默认高度 52、圆角 14，放大文字时允许增高。工具栏图标使用统一描边样式，点击区域为 48。字段提示在失焦或提交后显示，编辑会重新校验；表单业务错误仅呈现一次，真实验证码发送的人机验证反馈仍由原验证流程管理。注册显示第 1/2、2/2 步进度，第一步确认密码完成键进入下一步，第二步昵称完成键提交；小屏或键盘打开时可滚动。登录的模式切换入口位于主按钮下方。

登录后的设备验证保持参考 `DeviceChallengePage` 的原始尺寸：标题 28、验证码正文 18、标签 16、无边框灰底验证码输入框、52 高确认按钮。共享字段和按钮通过可选样式参数覆盖；登录、注册及找回密码的默认样式不变。该模块使用普通白底表单，与蓝色欢迎区的 `AuthEntryScaffold` 承担不同布局职责，因此新增独立共享框架，复用原来的输入、标签及按钮。

界面与导航验证位于 `test/pages/login/auth_pages_test.dart`；注册与找回密码的请求链验证位于对应模块测试目录。通过 `AUTH_PREVIEW_DIR` 参数导出真实 Flutter 页面预览，不使用真实账号或发送短信。
