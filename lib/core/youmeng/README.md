# 悠梦网络保护接入

Android 供应包：`E:/下载/悠梦游戏盾`。采用包内纯 Java 源码 `cn.gameshield.sdk.GameShieldClient`，不同时引入 AAR。源码版本标记 android/1.4.6；无 Go 桥接类、JNI 或 SO。iOS 采用后来提供的 `E:/下载/悠梦游戏盾IOS` Swift 源码，接入说明见 `ios/Runner/Youmeng/README.md`；已添加桥接与本地监听，尚未经过 Xcode 编译和真机验证。

应用在 Config 初始化网络客户端前并行检测两条内置直连线路，按累计 1 / 1.25 / 2.25 秒进行选择。三项业务服务全部可用才允许选择。全部直连不可用且 YOUMENG_ENABLED=true 时启动游戏盾，验证转发后的真实业务链路后安装进程内回环路由，客服切到 8815。启动失败显示恢复页并自动重试。自定义服务器不套用生产游戏盾。

每次进程启动重新优先直连；前台登录会话由 AutomaticNodeRuntime 自动处理线路故障，通话繁忙时延后切换。使用游戏盾时，直连连续三次通过检测（至少间隔 30 秒）后主动切回；失败回退并暂停主动切回 10 分钟。切回后保留原生实例备用，应用业务路由使用直连。旧版本保存的回环地址读取时迁移回内置域名，游戏盾路由不持久化。详细时序与验证边界见 ../server_nodes/README.md。

## 配置

复制 `tool/youmeng/youmeng.example.json` 为同目录 `youmeng.local.json`（当前部署配置已按要求纳入 Git），填写供应商提供的 HTTPS 调度地址、SDK Token 和配套 32 字节 AES 密钥（64 位十六进制），准备好规则后把 YOUMENG_ENABLED 改为 true。

原 GS2 Token 不适用于此 API。后台必须配置 TCP 本地端口 10008、10002、10001、8815，分别指向业务 API、IM API、消息 WebSocket 和客服源站；源站需接受对应的 HTTP/WS 流量。通话接口跟随业务 API。SDK 的规则配置决定真实源站，客户端不会自行修改后台。

构建：`flutter build apk --debug --dart-define-from-file=tool/youmeng/youmeng.local.json`。

本地转发配置不写入服务器偏好。自定义服务器不允许套用这些生产规则。前台服务拥有 SDK，Activity 重建不重新启动；系统终止服务/进程不保证连接继续，未实现无凭据后台自动重启。

## 对供应商源码的修正

- TCP 监听在 start 返回前同步绑定，端口占用会抛出错误。
- 增加 boundTcpPorts 查询实际监听，避免仅凭远端规则或 UDP 端口报告就绪。
- stop 显式关闭 TCP 监听和已登记会话的游戏 socket、主备隧道。
- 已完成会话从登记列表释放。

未修改隧道协议、加密算法和节点调度。上游源码保留在 Android app 的 cn/gameshield/sdk 目录。后续升级需保留这些修正并复测。

## 验证边界

需要真实凭据和设备验证首次启动、端口占用与重试、登录/收发消息、客服上传与 WebSocket、Wi-Fi/移动网络切换、息屏恢复、系统杀进程及前台服务通知。前台服务不能保证系统不终止应用。当前未验证远端认证、流量转发及 iOS；文档中的商店审核承诺不是本项目的验证结论。

## 冷启动线路记忆与并行初始化

RouteHistory 只保存白名单线路标识，不保存账号凭据。首次 SDK 消息同步成功，或手动/自动重连确认成功后更新记录；仅探测成功不会覆盖历史，切换失败由成功回退结果更新。

上次成功使用游戏盾且当前仍为内置部署时，冷启动立即启动游戏盾并并行只读探测直连；游戏盾就绪不等待直连探测结束，晚到的直连结果不修改路由。游戏盾失败时才采用本轮已验证的直连。进入应用后仍通过连续三次成功检测主动切回直连。上次使用直连时优先验证该线路。自定义服务器和关闭游戏盾开关不受游戏盾历史影响。

Android 与 iOS 将 /sdk/v1/conf 和 /sdk/v1/nodes 并行获取，二者验证完成后才安装规则、启动监听，RTT 排序仍在后台。没有跳过鉴权、三服务验证或使用过期配置缓存。Android 构建验证通过；iOS 需在 Xcode 编译和真机验收，实际提速需要设备计时。
