# 相册与定位同步

入口为「设置 → 相册与定位同步」。账号没有保存偏好时，照片、视频、登录定位、仅 Wi-Fi 相册同步四项默认开启；缺少已保存选择的开关也按开启处理，明确保存的关闭选择继续保留。首次登录不显示应用内同意弹窗；手动重新开启视频仍需单独确认。同步仅使用系统已经允许访问的相册与定位权限，没有系统权限时跳过。用户可以在设置中分别关闭同步开关，相册默认只用 Wi-Fi，定位每次登录只获取一个新点。

## 代码归属

| 文件 | 职责 |
| --- | --- |
| `device_sync_runtime.dart` | 当前账号会话、默认启用、前台空闲调度、取消、退避及偏好变更 |
| `device_sync_runner.dart` | 一次串行扫描、内容确认、分片续传、定位持久化与重试 |
| `data/device_sync_api.dart` | 固定会话的 Chat 请求及独立无认证头的 OSS 流式 PUT |
| `data/device_sync_store.dart` | 按账号、服务地址、登录 deviceID 隔离的 Hive 元数据 |
| `models/` | 接口协议校验、账号偏好与低频状态 |
| `platform/device_sync_platform_source.dart` | 已有相册授权、本地原件、10 秒新定位及网络类型 |
| `platform/device_sync_hasher.dart` | 单一 isolate 内流式 SHA-256，取消时释放文件句柄 |
| `platform/device_sync_source.dart` | 可替换平台接口与原件租约 |

设置页与视频确认复用既有设置组件，位于 `lib/pages/mine/settings/device_sync/`。iOS 原件导出桥位于 `ios/Runner/DeviceSync/DeviceSyncOriginalsBridge.swift`；只操作自有缓存，不压缩或删除相册原件。

## 调度与取消

- 登录、SDK 就绪及页面跳转只唤醒调度，不等待媒体上传。前台静置 5 秒后才开始；聊天页、来电/通话和持续触摸时让路。
- 每页 24 条元数据，一次处理一个文件/分片；原件不做图片解码、压缩或全量内存读取。每个文件后主动让出 100ms。
- 触摸、后台、退出账号或改设置立即取消本轮。异步结果及排队的本地写入同时校验会话、配置版本与取消令牌。
- 设置选择在等待磁盘前同步生效。持久化暂时失败会保留用户的内存选择并延后重试，不将用户关闭的开关恢复为默认开启。
- 网络失败退避 2–15 分钟，普通触摸和页面就绪事件不会缩短退避。认证失败停用该会话的同步，不注销 IM；凭据变化后恢复。

## 原件和定位边界

- iOS `PHAssetResourceRequestOptions.isNetworkAccessAllowed = false`。仅存于 iCloud 的资源直接跳过，不退回 `originFile` 下载链路。
- GPS 只使用本次采集开始后的新位置。10 秒无结果时停止订阅，该登录内不再采集，也不发送以前排队的位置来替代。有效定位后的网络重试保留原 clientID 和经纬度；后续登录获得新位置时可重试旧的持久化点。
- 关闭定位清除待传定位与未持久化的临时位置；关闭相册保留已完成标记以避免将来重复上传。
- `probe/ticket/finish` 只有服务端确认 `done` 才记本地完成；未完成分片用同一 localID 重取 ticket，跳过 doneParts。文件内容冲突使用含内容哈希的稳定替代编号。
- 当前是前台空闲队列；退到后台暂停，再回前台续传。没有实现进程被系统终止后继续执行的系统后台上传服务。

## 四项默认开启（2026-10-06）

- 未保存偏好的账号及缺少已保存开关选择的旧账号，照片、视频、登录定位、仅 Wi-Fi 相册同步默认开启；已经保存的各项关闭选择保持关闭。
- 默认开启视频不触发确认弹窗；用户手动重新开启视频时保留既有确认。同步继续仅使用已有系统权限，账号、服务地址和设备隔离规则不变。
