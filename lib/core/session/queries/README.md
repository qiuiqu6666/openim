# SDK 请求名额

`SdkQueryGate` 记录实际未完成的 SDK Future。调用方超时只结束本次等待，不释放原生请求的名额；迟到的成功和失败都被观察，原生请求结束后才释放。相同 key 可以复用一个在途请求，其他请求在总等待截止内排队。关闭或账号资格失效后不执行新的操作、不发布结果。

预读历史使用两个名额；会话定向快照、全量分页快照和连接唤醒分别使用一个名额，会话 ID 解析使用四个名额。这些是各模块上限，不能解释为全部 SDK 调用的全局上限，也不能取消已经发往原生的操作。

缓存有效期与请求在途时间分开管理。历史缓存过期不释放名额，刷新使用新的快照；恢复重試同样等待旧请求实际结束。原生永不回调时，该名额持续保留，调用方保留错误和手动重试入口，不能以不断叠加请求绕过阻塞。
