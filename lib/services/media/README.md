# 共享文件处理

`file_hasher.dart` 从设备同步已有的实现提取。每个 FileHasher 实例最多运行一个流式 SHA-256 worker；只传文件路径和消息端口，完成后返回摘要字符串，不传原图字节。取消先停止文件订阅，必要时终止 worker；dispose 取消该实例正在处理的令牌。

调用方拥有实例与操作取消令牌：设备同步保留 DeviceSyncHasher 兼容入口；收藏在本模块之上的业务队列中串行调用；朋友圈封面按页面生命周期使用。各业务实例彼此独立，大小限制、账号判断与上传幂等规则仍在业务层。长生命周期账号令牌不要为每个文件直接注册永久 Future 回调，收藏通过取消当前独立操作令牌传播账号失效。

提取过程保留原来的摘要、文件变更检查和取消算法；当前仅静态核对，未构建或运行测试。
