# 朋友圈媒体加载

`moments_media_image.dart` 是动态图片及封面的鉴权加载组件，监听授权与账号变化，清理内存图片及迟到请求。先读取编码图片的原始尺寸，再按显示区域和屏幕密度限制位图解码，最长边不超过 1080 像素。原始宽高回传给排布组件，避免缩略图解码限制改变单图比例；回调同样受会话、授权和请求代次保护。撤权时同时释放已完成的字节结果和内存图片缓存。

`moments_media_grid.dart` 按 99chat 排布动态三列图片及详情图片，保留真实预览入口。`moments_single_media_frame.dart` 使用服务端尺寸，缺省时使用当前资源的实际解码尺寸；单图比例及长图高度按参考规则处理。相同资源刷新省略尺寸时保留已确认的解码比例，资源 ID 或内容路径变化时清除。

现有公开入口 `../moments_media_preview.dart` 负责授权图片预览，仍由朋友圈信息流和详情页调用。真实数据通过 `MomentsRepository.downloadMedia` 获取，受保护内容只传内存字节给公共 `MediaBrowser`，不进入公共磁盘图片缓存。

当前选中的原图先加载，成功后即可显示；仅相邻两页的缩略图独立预取，九图动态不会同时启动其余八张下载。切页优先升级原图，再准备新的邻页，已下载缩略图不重复请求。迟到缩略图不能覆盖已升级内容；单图失败只影响该图的重试。初始加载、失败和撤权状态沿用图片查看器的深色背景。页面持有加载状态、授权快照和图片字节，退出、授权变化、账号切换或替换资源/仓储时清理内存图片缓存，未完成请求不写回已失效页面。

仓储分页继续保留版本、删除标识和好友权限检查；一页更新批量提交到共享信息流及已加载相册，加载开始与完成各通知一次，不按每条记录重复复制列表。

测试：`test/pages/moments/media/moments_media_preview_loading_test.dart` 覆盖当前图优先、邻页预取、独立失败重试、跨页原图升级、资源替换和授权/退出迟到结果；`moments_media_image_decode_test.dart` 验证受限解码、原始比例回传和撤权后清缓存；`moments_media_likes_preview_test.dart` 验证实际点赞页及媒体加载/失败亮暗状态，设置 `EXPORT_MOMENTS_UI_PREVIEW=1` 可独立导出预览。既有受保护缓存与页面流程测试继续保留。
