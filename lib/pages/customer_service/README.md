# 在线客服

公开入口为 `customer_service.dart` 的 `showCustomerServiceSheet`。会话列表顶部客服按钮及设置中的帮助反馈入口使用同一面板。

## 参考与复用

对照本地 99chat 的 `customer_service_sheet.dart`、`customer_service_static_page.dart` 和 `kefu_visitor_api.dart`：从底部打开屏幕高度 80% 的面板，展示八个问题分类、问题详情、文字/图片/视频客服会话。复用当前应用的毛玻璃组件、设置操作菜单、相册选择器、媒体预览、主题 Token 和公开平台配置。独立的访客聊天协议由本模块维护，不复用 OpenIM 好友会话控制器。

八个分类按钮固定在顶部，输入框保持在底部。问题列表或选中的答案、真实客服消息按顺序放在下方同一个聊天画布中，共用一个滚动区域。问答卡片按内容自然展开，不覆盖消息、不固定在顶部，也没有独立的内部滚动。长答案、小屏、大字号或键盘展开时可直接拖动画布浏览全部内容。顶部分类区按内容高度显示；空间过小时在固定区域内滚动，以保留下方聊天的可用空间。切换分类会回到新分类问题列表，保留消息和输入草稿。向上查看历史或问答时，新消息保留当前阅读位置；接近底部时跟随新消息，主动发送文字或附件后回到最新消息。

源实现来自 99chat（Apache-2.0）；许可及来源记录见 `docs/third-party-assets.md`。

## 配置和真实数据

按用户最新要求，默认客服 REST 地址为 `http://129.226.192.93:8815`，实时地址为 `ws://129.226.192.93:8815/cable`，inboxIdentifier 为 `JucC6gvPuKjfzZxLtT5ftaiQ`。可通过构建定义 `CUSTOMER_SERVICE_BASE_URL` 覆盖地址；inbox 优先读取 `INBOX_IDENTIFIER`，其次读取 `CUSTOMER_SERVICE_INBOX_IDENTIFIER`。新地址不带 `/kefu` 前缀，公开访客接口从 `/public/api/v1/inboxes/{inbox}/contacts` 开始拼接。

`data/` 使用访客公开 HTTP 接口创建联系人/会话、拉取和发送消息，通过 Action Cable 接收客服消息与输入状态。使用独立 HTTP 客户端，不传当前 OpenIM token；若配置为 HTTPS/WSS，仍保留标准 TLS 校验。FAQ 为帮助文案；官方网站读取当前应用的 `/chat/platform`，会话消息来自真实客服服务。

访客凭据按本地账号、客服地址、inbox 隔离保存，关闭重开恢复同一会话。地址或 inbox 改变后使用新的存储键，不会复用原部署的访客凭据；HTTPS 改为 HTTP 也会隔离之前的凭据。昵称及公开头像用于客服识别；内部 IM 用户 ID 不充当服务端访客 identifier，identifier 为本地生成的 UUID。附件地址由服务端返回：新根地址下的 `uploads/file.png` 或 `/uploads/file.png` 均解析为 `http://129.226.192.93:8815/uploads/file.png`；完整 HTTP(S) 地址保留原地址。

Android 主清单已设置 `android:usesCleartextTraffic="true"`，未配置另行覆盖的 `networkSecurityConfig`；iOS Runner 的 ATS 配置已设置 `NSAllowsArbitraryLoads=true`。现有平台配置允许 HTTP/WS，无需为本次地址切换修改平台文件；这不代表服务端已接受明文连接。

## 职责与生命周期

- `customer_service_sheet.dart`：弹层、动画、关闭及键盘避让。
- `customer_service_page.dart`：交互、应用/路由生命周期与现有组件接入。
- `customer_service_controller.dart`：会话初始化、消息合并、乐观发送和失败重试。
- `data/`：协议模型、HTTP、账号隔离存储和实时通道。
- `content/`、`widgets/`、`media/`：帮助内容、业务组件及附件处理。

页面拥有控制器（包括测试注入的控制器），关闭时取消请求、实时通道、重连及输入状态定时器。被其他路由覆盖或进入后台时暂停实时通道，恢复后订阅并补拉消息；退出/切换账号后的异步结果不更新旧页面。历史、实时消息和发送回执按服务端 ID/echo_id 合并，保留未发送成功的本地消息，重试复用原 echo_id。

实时通道未确认订阅或断线时，前台页面每 15 秒补拉消息（请求在途时合并），确认订阅后停止轮询。轮询仍请求真实 HTTP 消息接口，正在输入提示依赖实时订阅。原部署 `https://119.28.179.146:8081/kefu` 的 `/kefu/cable` 曾在保留标准 TLS 的只读握手检查中返回 HTTP 400；此记录仅属于原部署，不能用于判断新部署的实时状态。HTTP 创建会话、上传和人工往返未通过真实账号进行验收。

最多选择九个图片或视频，单附件不超过 40 MB；原始图片保留动画和透明度。临时视频封面归本页面所有，关闭后清理。客服附件预览复用普通媒体浏览器。
