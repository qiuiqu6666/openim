# 更新检查与强制更新

登录页 onReady 和首页 onReady 共用 AppController.autoCheckVersionUpgrade 的进行中任务。手动登录和更新检查并行，检查仍在进行时可登录进入首页。检查结果命中强制更新或失败重试拦截后，updateBlocksNavigation 阻止登录完成的路由替换移除弹窗；结果在首页返回时直接覆盖首页。无需账号的 /chat/platform 接口提供平台版本配置。成功检查在本次启动复用，失败或页面失效不缓存为成功。

请求失败自动重试两次（1 秒、3 秒）；仍失败则显示不可返回关闭的检查失败弹窗。重试按钮在重新获得配置前持续保留弹窗，成功后重新判断最低版本。未联网且无法验证最低版本时不能通过该检查。

安装版本低于 minVersion 时，不受灰度比例影响。缺失、非 HTTP(S) 或无主机的下载地址也保留强制弹窗；每次点击重新获取配置，让后台修正地址后可直接重试。打开外部下载页面不等于完成安装，强制弹窗保留。外部路由清理也不记作检查成功。

复用现有平台更新弹窗、颜色和尺寸 token；可选更新仍允许关闭。closeOnSuccess 仅供检查失败后的重试流程使用，强制版本更新不设置该选项。测试覆盖自动重试、无效链接拦截、后台地址恢复、失败后重试、返回关闭限制及现有亮暗主题/大字体展示。
