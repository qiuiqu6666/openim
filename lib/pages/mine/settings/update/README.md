# 版本更新

## Android：先下载校验，再提示安装

登录页和首页调用共享 `AndroidUpdateRuntime`，生命周期独立于登录账号和页面。
`android_update_controller.dart` 决定灰度、目标版本、下载、校验和重试；
`android_update_runtime.dart` 管理前后台、通话避让、弹窗和 24 小时普通更新稍后提醒；
`android_update_platform.dart` 连接原生桥。

原生模块位于 `android/app/src/main/java/io/openim/update/`：系统 DownloadManager
持久化下载任务并处理断网续传，允许移动网络、禁止漫游，不弹应用内下载框。
系统可能展示下载通知。应用在前台每 5 秒查询进度，后台不轮询正常下载进度，系统继续下载。
失败状态在进程仍被系统调度时继续自动重试；网络从断开恢复时立即重试，不必等待退避计时。
重复联网通知不重复触发请求，接口仍不可达时继续退避。进程被系统挂起或结束后，系统管理
可恢复的下载任务；回到前台或重启 App 后重新检查并恢复终止的失败任务，无需手动点击。
同一安装包复用任务；启动后采用已有任务，下载完成重新校验。

下载文件复制到应用私有目录，后台线程校验 SHA-256、大小、包名、签名、版本名及
versionCode；必须高于实际安装版本。当前采取签名完全匹配，密钥轮换需另行实现受信任签名链策略。
校验完成后重新获取配置，已撤回或替换的版本不提示。只有在前台且没有通话时显示安装弹窗。
普通更新可关闭，24 小时后再提醒；手动检查可提前恢复提示。强更忽略灰度、不提供关闭按钮。
打开系统安装器不视为成功，取消后仍保留安装包。首次安装权限在点击安装时请求；返回授权页后
重新检查配置再继续安装。再次安装会重新校验私有安装包。

成功与否以实际安装版本为准；升级后检查清理旧文件。直链下载失败不会阻断使用，重试从 30 秒递增至
最多 15 分钟；设置页显示进度、校验、待安装或“正在自动恢复更新”，失败时提供 HTTPS 官网备用入口。
正常配置每 15 分钟刷新，回前台刷新，弹窗显示期间每分钟刷新；撤回后移除更新弹窗，恢复使用。
`UpgradeManger.updateBlocksNavigation` 在已校验安装包的强更弹窗或兼容网页强更弹窗显示期间阻止登录路由替换。

## HTTP 字段

无需 Token 的 `GET /chat/platform`，使用 `data.android`：

| 字段 | 说明 |
|---|---|
| latestVersion | 完整版本，如 `3.0.1+2028`；兼容回退 version |
| minVersion | 最低允许版本；空表示普通更新 |
| grayRatio | 普通更新 0..100，0 必须显式返回；强更不受影响 |
| downloadLink | HTTPS APK 直链，不能使用官网 HTML 页面 |
| downloadURL | 备用官网下载页 |
| changelog | 更新说明，最多 4000 字符 |
| packageSha256 | APK 文件 SHA-256，64 位十六进制 |
| packageSize | APK 字节数，1..2147483648；兼容 JSON 数值和 protobuf 字符串 |
| versionCode | APK 实际构建号，必须与 latestVersion 的 + 后数字一致 |

没有 `downloadLink` 时沿用 `downloadURL` 网页更新提示：低于 `minVersion` 的版本显示不可关闭的强更弹窗，
打开网页、返回 App、网页打开失败或后续配置请求失败均不解除限制。已确认的网页强更要求保存到本地，
离线重启仍保留；实际安装版本达到最低版本或服务端撤回要求后解除。普通更新允许稍后处理，并遵守灰度比例。
后台补充有效直链及完整元数据后，切换为后台下载，下载期间可继续使用。
已有 `downloadLink` 但安装包元数据不完整时不下载、不锁住用户，自动重试获取配置。
`tool/android_update/release_manifest.py` 从正式 APK 读取版本、计算大小和 SHA-256，
输出 Android 字段，不能将它作为完整平台 PUT 请求覆盖 iOS/官网配置。
服务端改动包位于 `E:/openim/artifacts/android-update-20261014/server`，包含数据库字段、
protobuf、HTTP 显式输出、管理员校验与后台表单。客户端代码完成不代表服务已发布或 APK 已上传。

## iOS 与兼容入口

`widgets/platform_update.dart` 为现有公开入口。Android 转入下载模块；iOS 保留外部下载页
及现有重试/强更策略。公共 `platform_update_dialog.dart` 新增可控关闭信号和安装器返回后
保留弹窗选项，默认行为不变。旧 UpgradeInfoV2 不参与 Android 新更新流程。

## 验证与发布

测试在 `test/pages/mine/settings/update/`，覆盖状态机、前后台/通话避让、普通更新稍后提醒、
强更、配置撤回、权限返回、下载失败、校验失败、安装取消及亮暗主题/大字体。
原生调用和真实覆盖安装还需 Android 真机验证，构建通过不能代替安装器验收。

发布先部署兼容接口和后台，再上传与签名/版本匹配的正式 APK 并检查直链，填入准确元数据。
先验证普通灰度更新，再提高 minVersion。已安装的旧客户端仍走旧流程，无法通过接口单独获得静默下载能力。
