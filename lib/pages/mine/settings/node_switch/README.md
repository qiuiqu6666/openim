# 当前节点与测速

节点地址复用 core/server_nodes 的 NodeEndpoint：生产环境只显示直连节点01，已移除 HTTPS/WSS 域名节点；自定义服务器只显示自身。选中标记代表当前连接，页面不公开底层地址。启动检测结果只用于首次手动测速前展示。

用户手动测速时，并行请求每个候选节点 Chat API 的 GET /chat/platform，各自使用独立的无账号凭据客户端。开始后清除旧结果，每行独立显示测速中、成功耗时或异常，所有请求结束后记录完成时间。仅有效成功响应判定正常；该结果仅代表 Chat 服务响应耗时，不代表下载带宽或完整 IM 可用性。手动测速不修改登录或 SDK 配置。

重复点击共用进行中的请求；离开前台或销毁页面取消请求，节点配置变化后忽略旧结果。界面复用设置页组件与亮暗主题颜色。

对照 reference-99chat/lib/src/pages/settings/node_switch_page.dart 的所有节点测速、逐行反馈与节点点击行为，复用设置页组件，没有新增重复页面组件。点击未选中的节点会通过 core/server_nodes/ManualNodeSwitchRuntime 显式立即切换，自动测速仍不改变连接。每次冷启动仍按原策略重新选路。

手动切换先无凭据检查目标节点三项服务，成功后复用 IMController 的退出、初始化、登录链路，同时更新 Chat、IM API、WebSocket 和共享 HTTP 地址；保留账号凭据，不清空消息数据库。等待实际连接成功后才更新勾选标记；失败时尝试恢复旧节点，恢复失败明确提示检查网络并重启。全局协调器防重复切换，通话中拒绝切换，预检期间离开前台或关闭页面取消操作，账号改变后不恢复旧账号。重新初始化不广播启动事件，避免重复触发启动页自动登录。

验证：test/node_probe_controller_test.dart 覆盖单节点请求、重复点击、失败覆盖旧结果、配置变化及前后台取消；test/pages/mine/settings/node_switch/node_switch_layout_test.dart 覆盖单节点展示、亮暗主题、窄屏/横屏、大字号与已选节点点击；test/core/server_nodes/manual_node_switch* 覆盖重连成功、预检失败、回退、账号替换和 SDK 调用顺序。SDK 调用使用测试通道，不能代替真机连接验收。

## 节点03（游戏盾）

节点页使用 NodeEndpoint.selectable 显示两条直连和节点03，启动选路仍只使用 builtIn 直连列表，避免将未启动的回环端口混入直连检测。自定义部署仍只显示自身。

节点03 对应游戏盾，页面不公开技术名称。点击该行可手动切换：按需启动游戏盾，检查三项服务可用性后重连，确认连接成功后更新选中状态；失败时保留或恢复原节点。测速、切换进行中及当前已选中的节点不可重复点击。其他节点不可用时的自动兜底策略保持不变。进入页面不启动；手动测速节点03仍按需启动并测量 Chat 响应，不修改当前连接。自动切换检查完整三项服务，未启用游戏盾的构建不会启动该服务。

页面监听进程线路变更更新选中状态；使用游戏盾后，直连连续恢复仍会主动切回。
# 重连与消息恢复

切换仍由同一个 SDK 会话队列串行完成退出、重建连接和登录，避免旧操作影响新连接。路由专用登录跳过已经完成的重复清理；普通登录和账号切换仍保留原来的清理保护。同账号切换保留已有用户资料对象，页面、输入和历史消息继续由原来的页面控制器持有，不重新导航或清空列表。

确认连接成功后立即后台调用现有连接恢复器，触发 SDK 增量同步及聊天窗口历史校对。补齐不阻塞节点切换结束；失败沿用恢复器重试，账号变化或控制器关闭后旧结果失效。已发送消息仍由 SDK 的消息标识和历史合并逻辑去重，不盲目重发结果不确定的发送请求。

这不是零中断连接迁移：原生退出、初始化、登录和服务端响应仍需要时间，保留失败回退与通话中禁止切换保护。不要通过超时后并发执行原生登录/退出来制造更短的表面等待。
