# 当前节点与测速

节点地址直接读取 Config 的 Chat API、OpenIM API 和 WebSocket 配置，包括已保存的服务器配置。页面及登录节点入口仅显示“节点01”，不公开底层地址。当前只展示一个实际节点，不创建备用地址，也不修改登录或 SDK 配置。

用户手动测速时，通过独立的无账号凭据客户端请求 Chat API 的 GET /chat/platform。仅有效成功响应判定正常，显示请求耗时；HTTP 或业务响应失败显示异常。该结果仅代表 Chat 服务。

重复点击共用进行中的请求；离开前台或销毁页面取消请求，节点配置变化后忽略旧结果。界面复用设置页组件与亮暗主题颜色。
