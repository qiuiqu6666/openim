# 我的群组

普通列表保留 `GroupListLogic` 的 SDK 分页、创建/加入分类、下拉刷新、同步结束更新和群聊进入流程。每页默认 100 条，按需上拉加载；偏移按 SDK 原始页数量前进。某页没有当前分类的新群时继续读取后续页，直到出现新群或 SDK 数据结束，不能把过滤后的空页当作整个分类为空。失败保留原列表和偏移，允许重试。

按用户最新要求，普通列表、搜索结果和群选择器均使用惰性构建的普通列表，保持 SDK 原始顺序，移除字母索引、分组标题、拼音转换与排序，也不再为索引等待全量分页加载。通讯录好友的字母索引不变。

`count/GroupCountFooter` 对照 99chat 同页的群数量页脚，在全部分页加载完成后的列表末尾居中显示“共 X 个群聊”，避免把已加载数量误报为总数。数量来自当前创建/加入分类，搜索时使用匹配结果数量；确认空结果显示 0，加载或失败时不显示误导性的 0。页脚使用现有目录文字与间距 token、底部安全区，不参与群选择。

搜索参考 99chat `lib/src/group_list.dart` 的顶部目录搜索与 250ms 合并输入，复用现有 `SearchBox`、`ContactCardPickerTokens` 和空态/重试组件。输入群名或群 ID 调用现有 OpenIM `searchGroups`（两种字段均启用），不局限于已经加载的第一页。结果按 `ownerUserID` 分到“我创建的/我加入的”，切换分类保持关键词，不重复搜索；清空回到原分页列表。

`search/GroupListSearch` 单独管理搜索、加载、失败重试及输入生命周期。新关键词清除旧结果，响应按查询版本、账号和 token 校验，避免乱序、清空、退出或切换账号后的迟到写入；页面关闭时取消计时器、释放输入控制器。继续使用现有 SDK 同步结束订阅刷新当前搜索，不增加监听器。搜索行沿用原点击和可选群权限限制、群名称及直播头像组件，支持亮暗主题。

搜索范围以当前 SDK 已同步的群目录为准；没有群消息正文搜索。搜索模式不沿用普通列表的分页操作，失败可通过空态按钮重试。
