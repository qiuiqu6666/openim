# 群组选择

`SelectContactsFromGroupPage` 使用现有 OpenIM 已加入群组列表、GetX 控制器和共享联系人选择状态。参考 99chat `forward_message_screen.dart` 的群组搜索，单选、多选都在顶部复用 `SearchBox` 与 `ContactCardPickerTokens`，支持亮暗主题。

输入按群名称或群 ID 即时过滤，忽略大小写和首尾空白，不额外请求接口。清空恢复列表，查询变化回到顶部，提交或拖动列表收起键盘；空结果、加载和重试沿用现有占位组件。

列表及搜索结果使用 `ListView.builder` 按 SDK 原始顺序惰性构建，不做拼音转换、排序或字母分组。移除右侧字母索引及其占用空间，行高仍随大字体扩展，群对象及选择身份保持不变。

多选的全选/取消全选只作用于匹配结果，排除默认禁选项；不影响隐藏的已选群组。空结果不标记为全选，不改写群组原始数据、收件人 ID 或确认流程。搜索控制器由现有 GetX 生命周期释放。
