# 注册模块

主入口为 `RegisterPage` / `RegisterLogic`。第一步填写账号、验证码、密码及确认密码，验证码校验成功后进入现有 `SetPasswordPage` 路由。第二步填写昵称、选填头像并显示真实图片预览，点击完成注册后创建账号。返回上一步保留账号、密码、昵称及所选头像的内存草稿。

`rules/` 保存密码和昵称本地校验，字段在失焦或提交后显示当前语言的提示。验证码发送继续复用公共人机验证流程。

`session/registration_session.dart` 负责注册后的已有账号存储与 SDK 登录。每次请求持有用户 ID、Chat token 和 IM token 的快照，页面关闭或其他会话替换凭据后停止后续处理。注册未返回完整登录凭据时，用首次提交的账号及密码调用现有登录接口，取得完整凭据后登录 SDK。选择头像时，登录后使用现有 OpenIM 文件上传及资料更新接口完成上传；资料保存成功后才完成注册流程，未选头像使用服务端默认头像。

验证码校验、注册请求均关闭底层自动错误提示，当前有效页面通过 `IMViews.showToast` 显示一次公共居中提示。业务错误按发生步骤的接口路径和当前语言映射，保留表单内容供重试。账号创建后锁定昵称、密码及上一步入口；后续登录未完成时显示“继续完成注册”，头像上传失败时显示“重试上传头像”，可重新选图后继续。两种重试都不重复创建账号。

旧 `verify_phone/` 路由保留兼容，第二步 `set_password/` 在旧入口未携带密码时显示独立的密码补填组件。头像选择界面独立位于 `set_password/widgets/registration_avatar_picker.dart`，控制器继续持有选择、上传及关闭保护。

测试位于 `test/pages/register/`；页面、键盘、主题及滚动验证位于 `test/pages/login/auth_pages_test.dart`。测试使用模拟请求和 SDK，不创建真实账号或发送短信。
