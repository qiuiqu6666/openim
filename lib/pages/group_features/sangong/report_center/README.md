# 当前群报表中心

入口位于管理首页和游戏规则页，沿用 `canManage`：群主及获授权帮工可查看；不向普通成员开放群内其他用户的财务资料。服务端再次验证当前群管理权限。

- 总览：当前积分、人数、团队负责人、所选经营批次牌局/有效结算/下注/庄净/抽水/返水，以及账变分类合计。实时状态明确独立于历史批次。
- 用户：昵称搜索或完整 IM ID 查询，积分、上下级、闲家/庄家流水、上下分、账变净额、返水及批次最后余额；可进入既有用户详情及完整账变。
- 团队：负责人、本人和下级汇总、直接/全部下级切换及成员明细。
- 账变：按批次、用户和类型查询，展开查看操作人、余额、来源、备注及时间。
- 牌局：状态、开奖、有效结算快照、庄家/合庄及闲家资金明细。

`data` 管理一次可见查询及分页；`pages` 组织导航；`widgets` 复用主题指标、分页和流水展示。生产数据使用 Sangong V2 API，不使用预览数据。

列表每页 50 条，不以当前页代替全批次统计。分页版本变化时清空旧记录并提示刷新，避免拼接不同版本的账目。离开当前群、切换账号或失去权限即清空私密内容；迟到响应不会恢复旧数据。批次变更后用户详情和账变使用相同 sessionId。查询完全只读，不修改余额、不发送群消息。

测试覆盖帮工入口、亮暗主题、小屏、按需加载、分页版本变化、切群迟到响应；接口集成覆盖真实汇总、退款、冲正、搜索、团队和非管理员拒绝访问。

## 展示层次

总览以全群实时积分为首卡，批次经营结果与实时局状态分别分区；规则折叠，账变分类可直接进入相应记录。金额使用千位分隔，增减使用正负号和文字，缺失值显示破折号。

用户/团队以身份、当前积分或直属人数为首层，明细展开再展示流水；牌局以开奖、庄家与合庄、闲家结算分区，各门下注逐门标注，不显示原始字典。账变显示增加/减少、变动后积分和时间，操作来源与备注保留在展开区。主题色、卡片与原生列表沿用 Flutter 当前主题，支持亮暗主题及底部安全区域。积分分组保持隐藏。
