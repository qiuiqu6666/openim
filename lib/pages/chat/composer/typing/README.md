# 输入状态隐私

“朋友权限 → 展示输入状态”默认开启，复用原页面的 SettingsGroup、_ToggleCell 和 AppSwitch，位于上线时间权限下方。通过 OpenIM 本人资料扩展字段 `showTypingStatus` 保存账号级权限，并沿用 SDK 多端本人资料通知。关闭不影响接收对方输入状态、文本发送或草稿。

`core/privacy/typing_visibility_sync.dart` 读取当前 SDK 资料，保留其他扩展字段后调用 `setSelfInfo`，服务器确认后更新本地缓存。保存失败不显示保存成功。登录、SDK 同步完成、本人资料更新、既有前台资料刷新和进入设置页会更新缓存。设置页面监听同一账号变化，无需重新进入；旧异步读取不能覆盖期间收到的更新。会话令牌、服务器和账号发生变化时丢弃迟到结果。无字段默认开启；旧版本客户端需升级才能遵守新权限。SDK 扩展字段整体写入，遵循现有资料同步冲突语义，没有新增服务端原子字段更新接口。

`typing_visibility_preferences.dart` 仅维护账号缓存。`ChatTypingSender` 在每次调用 OpenIM `changeInputStates` 前核对当前会话和权限；关闭时清理本实例曾发布的输入状态。串行处理保证关闭前已发出的开始请求结束后才发送停止，排队的开始请求会重新检查权限而被丢弃。停止成功前保留清理义务，网络错误不干扰编辑、不自动重试。关闭不会撤销已经发出的网络包，远端最终清理仍依赖 SDK 通知到达或原有超时。

ChatLogic 仅负责接线与释放；权限和发送状态不继续堆入主控制器。账号退出或页面销毁后，排队回调不能继续发送。

验证：初版 44 项设置/输入回归通过；账号同步改动后 31 项相关回归通过，包括模拟另一端更新、空缓存读取服务器值、保留签名等扩展字段、保存失败、迟到回包、账号切换及开关深浅主题/大字号。保存需要联网，失败沿用页面错误提示；缓存支持离线读取。未执行双端真机端到端或 TalkBack/VoiceOver 操作验证。
