# 聊天收藏适配

`ChatFavoritesController` 负责消息收藏、当前会话收藏选择、恢复发送与重试适配；数据存储、发送日志和幂等恢复仍归已有收藏服务。

`FavoritePickerSheet` 为聊天选择器，继续复用收藏业务页中的现有公开组件。后续整理收藏主模块时再将该公共列表抽出，避免本次同时改动整个收藏业务链路。

2026-10-05 最新样式参照 99chat 活跃 `lib/src/pages/favorites/favorite_picker_sheet.dart`：顶部圆角 24、38×5 拖动条、24 号标题、胶囊分类与搜索/管理按钮，搜索点击展开。按用户最新要求，面板固定为 78% 屏高并受可用视口及键盘空间限制，分类切换不再按内容条数收缩。行卡片使用 16 圆角、文字/媒体缩略图、真实来源与收藏时间；右侧只保留垂直居中的圆形发送箭头，视觉尺寸 32、点击范围 48、图标 26，取消重复的更多菜单。语音独立使用最大宽 144、高 48 的横条，依据可用宽度收缩，为标题保留空间；声音图形与时长分列左右。分类统计来自已加载未筛选数据，分页尚未结束时以 `N+` 显示，避免伪造全库总数。共享列表通过 `pickerStyle` 适配，此入口专用的筛选和卡片组件位于 `widgets/`。

左侧条目仍打开只读详情以查看图片或播放音视频；右侧发送到打开时固定的目标。发送中显示进度，保留服务能力、可发送状态、账号和未知结果锁定。管理入口复用现有收藏页，返回后恢复选择器筛选。发送区与查看区独立，禁用发送点击不会落到查看操作。主题色和尺寸统一归 `FavoritePickerTokens`、`FavoriteMediaTokens`、`AppTokens`。管理列表也复用该语音尺寸；没有新增业务接口。

会话有效性与账号一致性由页面和发送模块提供，迟到结果不更新旧页面。选择器测试位于 `test/pages/chat/favorites/`，发送生命周期测试位于 `test/pages/chat/messages/`。

`FavoritePickerContent` 只负责固定列表区域内的加载与内容淡入。始终保留一份 ListView 和其滚动控制器，加载时在该区域显示进度，结果完成后 180ms 淡入；不复制新旧列表或依据动画结束提交状态。快速切换替换正在执行的动画，减少动画设置直接显示结果。普通高度下的页脚保留 56 高的槽位并依据字体缩放，空分类也保留；可用高度较小时沿用紧凑工具栏。业务数据仍由现有 FavoriteRepository 提供，使用已有请求取消和查询代际保护，没有新增接口。
