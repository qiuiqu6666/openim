# 媒体附件

2026-10-15 图片发送排查：相册 MIME 查询最多等待 2 秒；缺失、异常或超时的元数据交给真实文件准备验证，HEIF 与大小写 MIME 可正常选择，取消已选图片不再重复查格式。HEIC/HEIF 的 JPEG 转换是必要步骤，失败或无 JPEG 输出会明确失败并继续批次，不再把 Core 无法解码的原文件作为压缩回退。普通 JPEG/PNG 等仍保留原文件回退。

长截图的可选顶部预览有独立的 5 秒总预算，包含排队、生成和上传；超时使用已上传原图及现有缩略图 URL 继续提交。迟到预览只清理自身临时文件，不能修改已提交的消息。原图上传仍保留 10 分钟上限，不用短预览预算截断弱网上传。

共享原生 SDK `recovery.30-image-upload.1` 为上传增加 9 分钟总期限，覆盖签名请求、PUT 及响应体，先于 Flutter 的 10 分钟等待上限取消底层网络请求；同内容上传锁改为可取消等待，超时/退出不占住后续同图重试。哈希计算和分片边界检查取消。此期限适用于共享文件上传能力；超慢的大文件会失败并保留手动重试语义，不自动重复发送聊天消息。原生回归使用本地 HTTP 服务模拟响应头/响应体卡住，并验证超时后同图重传、等待取消与 60 个并发任务互斥。

网络节点切换保持发送与显示的不同边界：旧连接的任务停止继续提交；同账号、同凭证下，尚未提交的气泡显示失败，已提交的气泡显示待核对，并继续接受原尝试的迟到确认。切回原节点不会复活旧任务。账号、凭证或 Home 任务代数改变后仍禁止向新会话发布旧结果。此处理不自动重发，也不提供进程被杀后的续传。

`diagnostics/chat_media_diagnostics.dart` 将 `chat_media` 结构化事件写入 SDK 日志，显式使用生产可保留的 Info（4），避免 `Logger.print` 的 release 关闭和 SDK `logs` 默认 Debug（5）被过滤。事件包括选择入口及阻止原因、读取与回退、压缩、创建 SDK 消息、原图/预览上传、节点取消和发送回执；`traceID`、`clientMsgID`、阶段耗时、异常类型与数值错误码用于关联。未初始化 SDK 时跳过记录，日志故障不影响发送；不记录图片内容、相册资源 ID、文件路径、URL、凭证或原始异常正文。日志随现有 SDK 日志导出/上传流程采集。

这次在当前客户端源码复核选图到原生桥接、Go 上传和图片解码；客户端没有 GitNexus 索引，SDK 使用 `openim-fast-recovery-final-20261015`（2026-10-15 索引，HEAD `88d76af`）辅助定位，并直接核对随应用携带的 Core 源码。没有用户现场日志，自动测试复现的是确定的故障路径，不能据此断言全部线上反馈只有同一原因。Windows 环境未验证 iOS 真机、iCloud 下载或实际弱网上传。

验证：169 项 Flutter 媒体/发送/压缩回归、修改范围 analyze、15 项源码锁测试、共享 Core 相关测试及 Android 四 ABI SDK 构建；安装包与 SDK 二进制核对见 `native_sdk/patch15/verification/recovery.30-image-upload.json`。iOS 必须执行同目录 `build-ios.sh` 重建当前共享 SDK，仅更新 Dart 不能获得原生上传取消修复。

相册导出失败、文件消失/为空或 30 秒不返回时，`preparation/chat_media_asset_loader.dart` 尝试读取同一资源的原文件；两种读取都失败则提示现有发送失败并继续后续图片。检查账号与任务生命周期后才接受文件。图片压缩最多等待 10 秒，超时使用已保留的原文件；SDK 图片消息创建最多等待 15 秒，迟到结果不能补发或重复插入。HEIC/HEIF 先通过现有公共压缩能力导出 JPEG 和匹配的 `.jpg` 文件名，避免交给不支持 HEIF 的 Core 解码器。仍保留 GIF 动画、PNG/WebP 的既有格式行为。失败发生在 SDK 创建消息之前时显示失败提示，不伪造气泡或发送成功。对应回归见 `preparation/` 和 `chat_album_send_test.dart`。

聊天气泡预览由 `ChatMediaPreviewSession` 持有会话级打开锁，从首次点击到浏览器关闭都忽略重复点击（包括其他气泡和消息行重建）。历史媒体查询最多等待 400ms；超时或失败使用当前已加载媒体和所点消息，慢查询回包后停止继续分页，不再触发导航。保留账号、凭证、聊天路由与消息到期检查。此降级图库仅含已加载消息，快速查询成功时保留完整历史图库。回归见 `chat_media_preview_session_test.dart`。

`ChatMediaController` 持有附件选择锁和待发送附件，负责相册、相机、文件、位置与音频文件选择、留置媒体及 SDK 消息构造。真实发送由注入的发送能力执行，语音转文字由语音模块执行。

`ChatPictureGallery` 根据消息快照异步检查本地文件并构造公共浏览器数据。原生选择、压缩、SDK 创建和音频时长检查完成后都核对会话生命周期；关闭释放待发送列表，延迟操作不再提交旧会话内容。

相册/相机返回后关闭工具栏，准备数量显示在输入框上方，SDK 消息创建完成后立即插入真实气泡并返回最新位置。按选择顺序逐个准备，同时通过发送队列提交已准备的消息。单个准备失败提示后继续下一项。已确认的批次由 `upload/chat_media_outbox.dart` 持有，关闭聊天不会取消准备、上传或消息提交；切换账号、凭证或退出登录会阻止后续提交。准备提示在本地处理结束后消失。

`chat_media_outbox_binding.dart` 只订阅当前聊天的状态，关闭页面取消订阅，重新进入恢复待发/失败消息及上传阶段，同一消息 ID 更新原气泡。目标会话及账号凭证在接受批次时固定。发送使用现有 `ChatMessageSender` 和 OpenIM SDK；30 秒未确认改为待核对，不自动重发，迟到成功回执仍会更新。上传失败在任务中记录，不依赖已销毁页面处理异常。Home 销毁时清空任务并失效旧批次，防止同账号重新登录复活旧任务。任务注册表为进程内状态，不提供杀进程后的自动续传。

当前窗口中的附件阶段/确认更新委托 `ChatDeliveryController.updateMessage`，仅通知对应消息行，保留早到的已读回执和时间标记；发送时间被 SDK 修正时才要求完整重算。成功/失败后释放页面的上传状态，避免长期发送累积通知器。上传百分比仍走独立的上传状态监听。

回归：`chat_media_outbox_test.dart` 覆盖准备中/上传中退出、重新进入、旧页面停止更新、账号切换/退出、上传失败及超时后迟到回执；原 `chat_album_send_test.dart` 中未注入任务所有者的场景保留底层控制器旧会话关闭契约。

图片先保留到独立命名的本地缓存，避免后续同名图片压缩覆盖正在上传的文件；压缩异常、空文件或无输出时回退到保留的非空原文件。附件准备只使用 SDK 创建的消息 ID，不伪造消息或提前显示发送成功。

附件选择锁只覆盖相册/拍摄窗口及视频质量确认；确认后立即释放，不等待整批文件读取、压缩或上传。后台准备期间可以继续打开相册、拍摄或文件入口。多批准备数量累加，每项完成时扣减，旧批次完成不能清空新批次计数，也不能释放新选择窗口的锁。`chat_album_send_test.dart` 覆盖这些交叠场景。

媒体预览在异步文件检查前冻结 SDK 消息内容与顺序，`messageAt(index)` 与每个实际 `MediaSource` 一一对应。跳过无媒体文件的消息不会造成索引错位；无消息 ID、越界或映射缺失返回 `null`，不会回退到最初点击的消息。浏览器数据保持固定，转发/删除先按该索引的 ID 核对当前消息，再使用当前有效 DTO，避免旧的转发和过期元数据。

`ChatMediaMessageLocator` 是聊天内预览的定位适配器。公共浏览器关闭预览后调用 `onViewInChat(index)`；应用继续使用原 `ChatLogic.jumpToDateMessage` 完成历史窗口及滚动，不另开聊天或实现 SDK 分页。已加载消息直接定位；离开当前窗口的消息先以当前 `conversationID` 和单个 `clientMsgID` 调用 SDK `findMessageList`，确认仍存在后使用 SDK 返回的消息定位，防止删除的旧快照被历史窗口重新带入。无效/已删除、到期和失败显示现有应用 Toast；账号、令牌、聊天路由失效或定位时被新页面覆盖则静默丢弃。

映射及定位回归：`chat_picture_gallery_test.dart`、`chat_media_message_locator_test.dart`。覆盖跳页、过滤与深拷贝、当前消息元数据、失效/过期、未加载时精确 SDK 契约、重复定位和晚回包保护。此接线仅用于当前聊天媒体入口，历史搜索和存储媒体入口仍保持原有行为。

测试：`test/pages/chat/media/`。公共图片组件测试仍在应用的公共组件测试中。

`widgets/chat_video_thumbnail.dart` 是原聊天消息行中的缩略图组件，现由聊天
与会话长按预览共同复用。异步检查本地文件，缺失时使用远端 snapshot，
保留路径更新、晚回包保护与限制解码尺寸；显示缩略图不创建视频播放器。

高频媒体：打开相册仅捕获一次深拷贝，返回动作消息仍提供独立副本；文件是否存在由查看器按当前页异步检查，避免逐张磁盘探测阻塞打开。压缩输出使用每次独立临时目录，防止同名照片准备/上传交叠覆盖。
