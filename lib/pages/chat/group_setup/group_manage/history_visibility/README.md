# 新成员历史消息可见性

目标：群管理增加“允许新成员查看历史消息”。开启时允许新成员查看入群前记录；关闭时只能查看入群后的记录。只允许当前群主和管理员修改。

## 当前接入缺口

当前依赖 `flutter_openim_sdk 3.8.3+hotfix.12` 的 `GroupInfo` 和群设置接口没有此开关。不能通过本地偏好或自行写入群 `ex` 宣称权限已经生效。必须先确认业务服务端接口与消息范围控制。

## 需要后端确认的约定

- 查询：明确返回当前群的布尔设置及当前用户是否可修改；不把缺失字段当作关闭。
- 保存：支持布尔设置，验证操作者仍属于该群且是群主/管理员，返回保存后的真实状态。
- 历史范围：服务端限制新成员可拉取的最早消息；覆盖正常入群、邀请入群、退群后重新加入。
- 策略变化：明确是否影响已加入的成员以及已同步的本地记录。
- 权限广播：群设置变化能触发刷新；退群、降权、退出账号后拒绝旧请求及旧响应。

## 前端接入位置

复用 `GroupManagePage` 的设置行、`AppSwitch`、亮暗主题与公共提示；状态及传输归本目录。保存使用 `GroupSetupLogic.capturePermissionContext` / `isPermissionContextCurrent` 防止切换群或账号后写入旧数据。其他既有群规则仍保留原权限规则。

开启说明：新成员可以查看入群前的聊天记录。

关闭说明：新成员只能查看入群后的聊天记录。

## 验收

群主、管理员可读写；普通成员不可写；失败不改变开关；连点只发一次；保存期间切换账号、退群或降权不回写状态。分别使用新入群账号验证开启/关闭后的消息范围，以及历史搜索、日期跳转和换设备登录。
