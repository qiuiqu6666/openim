# 新成员历史消息

手机端群管理的“新成员历史消息”入口仅群主可见。可选择“允许查看入群前消息”或“仅查看入群后消息”。只影响保存后新加入的成员，已有成员的历史权限不变。

接入已存在的服务端 `GroupInfo.ex.enableHistoryForNewMembers` 布尔字段，使用现有 SDK 群资料读写接口。缺失/null 默认允许；非法显式值按禁止显示，与服务端兼容。保存前重新读取角色和群资料，合并最新 ex，仅替换此字段；非 JSON 旧资料拒绝覆盖。失败保留选择并允许重试。

入口与保存检查群主身份，并使用页面打开时的权限上下文阻止账号切换、退群、降权后的请求或旧响应。重复保存被阻止。成功后更新群资料及既有群资料事件。

2026-10-23 已将服务端两个群资料更新接口同步收紧：群管理员不能改变新成员历史策略（包括删除字段恢复默认），但保留原策略时仍可修改其他群资料。群主可修改；后台已认证系统管理通道保留原权限。历史范围由现有服务端在入群时限制，不使用本地过滤模拟权限。没有修改已有成员范围、清空记录或 SDK 生命周期。
