# 群资料页首次加载

`GroupSetupLogic` 同步初始化会话与资料，路由未传会话时使用当前聊天会话，不再等待 SDK 查询后才初始化 `late` 字段和订阅。

进入页面时复制当前聊天的同群资料；只有聊天中已读取到同账号、同群的本人成员记录，且聊天仍标记在群内，才复用已入群状态和本人角色。不能单独依赖聊天默认值为 true 的 `isInGroup`。不从 SDK 快照填充成员账号或成员预览，成员预览继续使用现有受权限约束的 HTTP 来源。

已有资料立即展示，资料、本人角色和成员预览并行更新，同时重新核验入群状态。99chat 对照为 `lib/src/group_profile.dart` 的本地群资料/人数与成员占位处理。界面仍复用现有群资料卡片、主题颜色和成员占位。

`GroupSetupMembership` 区分未查到结果与确定退群，每次核验最多两次请求，单次 8 秒超时，失败后间隔 500 毫秒重试一次；重复刷新合并。核验失败保留已有资料，首次无资料时显示局部加载/重试，不展示删除会话入口。SDK 入退群事件、页面关闭、账号/令牌/服务端变化会使旧结果失效，退群会清除预览和管理入口。

SDK 本地入群查询首次返回 false 也会间隔 500 毫秒确认一次，期间不切到删除状态。同步开始/进行中废弃旧核验结果并保留已知资料；同步完成自动发起新核验，无需手动刷新。真实退群或被踢事件立即生效，后续同步完成与旧查询不能恢复成员权限，只有新的入群事件才能解除该限制。同步订阅由资料控制器持有并在关闭时取消。

成员区在首次请求开始前也显示占位，不能把初始空列表当成失败，只有真正失败才展示重试。相关测试在 `test/pages/chat/group_setup/loading/`，与群设置、成员身份测试一起运行；页面状态覆盖窄屏和亮暗主题。真实设备与线上弱网仍需联调确认。
