# 群聊提及提醒

`ChatMentionController` 保存进入会话时未读范围内的 @我 / @所有人消息，独立于会话已读回执和群 @ 标记清除。数据来自 OpenIM 本地提及消息分页搜索；以进入时的最新序号和未读数确定边界，避免已读回执抢先更新导致提醒消失。无序号时使用消息已读状态兜底。实时消息复用当前聊天的消息订阅。

页面复用 `NewMessageIndicator`，与返回底部胶囊纵向排列。点击复用 `focusSearchMessage` 的历史窗口定位及高亮，成功后移除该提醒，失败则保留供重试。撤回、删除、去重和关闭后异步返回均由控制器保护。

参考 99chat `lib/src/chat.dart` 向聊天组件传递 `groupAtInfoList` 的入口；本项目使用 OpenIM 数据和既有胶囊样式，不引入腾讯 SDK。
