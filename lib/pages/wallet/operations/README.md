# 钱包操作恢复和详情

`data/wallet_operation_coordinator.dart` 与 `wallet_operation_pending_store.dart` 管理提现/闪兑的冻结请求及持久恢复。数据按规范化服务地址与当前用户隔离，不保存支付密码；发送前保存 `submitted`，同账户同业务在途请求互斥。明确拒绝可沿用原业务单号修正密码；任何不确定结果禁止重发，已知真实订单号只走 GET 核对业务、金额、币种、地址和兑换目标。

确认结果先缓存，再保存元数据和派发账号隔离的余额/记录刷新。持久化失败不会转成第二次资金请求；新交易只能由独立用户操作清理已确定的原交易，再生成新业务单号。页面关闭及账号变化后不显示旧账户成功结果。

本目录维护状态卡、GET 订单详情页面和既有支付密码设置入口。复用钱包导航、颜色、金额输入、币种图标及在线客服，不修改既有红包/转账流程。测试与预览均使用假 API，不向生产服务发送资金。
