# 钱包扫一扫

`wallet_qr_scanner_page.dart` 是钱包和提现共用的业务适配，原
`../host/wallet_qr_scanner.dart` 保留兼容导出。相机、相册选图及后台二维码
解码、闪光灯、权限与页面生命周期、遮罩和布局统一复用
`../../../widgets/qr_scanner/`，与好友扫一扫使用同一实现。

相机和相册均返回去除首尾空白的实际二维码文本；不使用好友邀请解析器。
提现调用方继续以已有 TRON 校验和 URI 提取处理文本，不自动提交提现。
钱包首页保留原有扫码结果处理。扫描期间不会请求钱包接口。

“我的二维码”按 99chat 的钱包扫码模式打开现有个人二维码页，身份来自当前
OpenIM 用户，邀请来自真实好友邀请接口。返回扫描页恢复相机；没有生成
示例码。相册取消、失败和无有效码均留在扫描页，允许重试；
相机权限未允许时仍可使用相册。页面被覆盖、应用后台、选图期间暂停相机，
已关闭页的迟到识别不再导航。

展示沿用好友扫一扫已对照的 99chat 样式和公共 `QrScannerTokens`，
实际参考为本地 `reference-99chat/lib/src/qr_code_scanner_page.dart`，
钱包与提现入口分别在 `lib/src/pages/home_page.dart` 和
`lib/src/pages/wallet/withdraw_address_screen.dart`。
相机界面在日夜主题下均使用统一深色背景，按钮和提示支持五语言。
相关测试及可选真实组件预览位于 `test/pages/wallet/scanning/`；
原生相机和系统相册权限需在 Android/iOS 真机继续验收。
