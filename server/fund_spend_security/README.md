# 红包、闪兑、直播打赏统一资金风控

2026-10-21：三类支出接入现有转账安全规则：手机号或密码变更后两小时冷却、支付密码错误锁定、大额短信验证、现有请求频率与资金限额规则。

## 实现

- 安全检查和发码接口接受且仅接受一种 `transfer`、`withdrawal`、`packet`、`swap` 或 `tip`。
- 红包按总额判断阈值；普通群红包绑定单份金额和份数。闪兑绑定转出金额、币种方向及报价。打赏绑定最小货币单位、主播、群和场次。
- 最终扣款、冻结、短信消费在同一个 MongoDB 事务中执行，并重新检查凭证变更。失败回滚凭证和资金，已接受的订单优先返回原结果。
- 红包重复业务单号必须匹配原参数；成功重试保留群消息补发能力。打赏在事务内确认场次仍在直播且主播未变。
- 客户端复用已有安全验证弹窗；密码、短信验证码和 challenge 不写入待处理订单。
